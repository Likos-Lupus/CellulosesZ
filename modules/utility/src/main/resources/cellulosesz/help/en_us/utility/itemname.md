# /itemname

Rename the item in your hand.

## Behavior

Sets the held item's custom name. With no name, clears it. Names longer than the server limit
(default 64 characters) are rejected.

## Examples

- `/itemname Blade of the Dawn`
- `/itemname`

## Failures

- You're not holding an item.
- The name is longer than the server limit.

## Related commands
