# /repair

修复物品。

## 参数

- `hand`（默认）或 `all`。
- `player`：可选，修复该玩家的物品而非自己的。

## 行为

把受影响物品的耐久恢复满。`hand` 修复主手中的物品；`all` 修复背包与副手，服务器允许时也包括盔甲。附魔物品默认
跳过，除非服务器允许修复。管理员命令。

## 示例

- `/repair`
- `/repair all`
- `/repair hand Alice`

## 失败情形

- 指定玩家不在线。
- 没有需要修复的物品。
- 服务器已关闭物品修复。

## 相关命令

- `/more`、`/condense`
