# /balancetop

Show the balance ranking, highest first.

## Behavior

Lists ranked accounts by balance, highest first, one page at a time. Ties are broken by account id
so the order is stable.

## Parameters

- `page`: optional page number, starting at 1.

## Example

- `/balancetop`
- `/balancetop 2`

## Related

- `/balance`, `/pay`
