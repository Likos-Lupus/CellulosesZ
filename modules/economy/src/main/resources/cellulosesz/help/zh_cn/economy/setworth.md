# /setworth

设置服务器收购某个物品的价格。

## 行为

不指定物品 ID 时，设置手中物品的价值；指定物品 ID 时，设置该物品的价值。价格会被持久化，并同时更新内存中的价格
表，因此后续的 `/worth` 与 `/sell` 会立即生效。每次写入都会把操作者记录为 `updated_by`。

价格是精确的两位小数，例如 `1.50`；价格必须为正。

## 参数

- `item`：可选的物品 ID，格式为 `namespace:path`；默认使用手中的物品。
- `price`：精确的单价，一个正的两位小数。

## 示例

- `/setworth 2.50`
- `/setworth minecraft:diamond 100.00`

## 相关命令

- `/worth`、`/sell`
