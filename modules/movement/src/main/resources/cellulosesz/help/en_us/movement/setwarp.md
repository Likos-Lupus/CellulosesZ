# /setwarp

Create or update a server warp at your position.

## Behavior

Requires moderator permission. Reusing an existing name overwrites that warp.

## Parameters

- `name`: the warp name. Lowercase letters, digits, `_` and `-`, up to 32 characters.

## Example

- `/setwarp market`

## Failures

- The name is invalid.
- Missing permission.

## Related

- `/warp`, `/warps`, `/delwarp`
