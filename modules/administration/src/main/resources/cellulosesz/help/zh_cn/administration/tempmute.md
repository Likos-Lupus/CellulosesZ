# /tempmute

临时禁言一个玩家。

## 行为

与 `/mute` 相同，但禁言会在指定时长后结束，且受服务器上限约束。禁言在生效前先写入存储，并记入审计记录。

## 参数

- `player`：要禁言的玩家。
- `duration`：例如 `1h` 或 `2d`。
- `reason`：可选原因，由你填写。

## 示例

- `/tempmute Alice 2h`

## 失败情形

- 时长不合法，或超过服务器上限。
- 找不到该名称对应的账号记录。
- 目标受保护。
- 暂时无法读取或保存禁言记录。

## 相关命令

- `/mute`、`/unmute`、`/muteinfo`
