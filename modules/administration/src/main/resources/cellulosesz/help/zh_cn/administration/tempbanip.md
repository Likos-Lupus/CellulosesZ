# /tempbanip

临时封禁一个 IP 地址。

## 行为

与 `/banip` 相同，但封禁会在指定时长后到期，且受服务器上限约束。地址在玩家进入服务器时生效，并记入审计记录。

## 参数

- `target`：IP 地址，或使用其地址的在线玩家。
- `duration`：例如 `1d` 或 `12h`。
- `reason`：可选原因，由你填写。

## 示例

- `/tempbanip 203.0.113.7 7d`

## 失败情形

- 地址无法解析。
- 时长不合法，或超过服务器上限。
- 地址属于受保护的玩家。

## 相关命令

- `/banip`、`/unbanip`
