# /fireball

发射火球。

## 行为

朝你的视线方向发射一枚投掷物。可选类型包括 `small`、`large`（默认）、`dragon` 和 `wither`。可选的 speed 会
缩放发射速度。

## 参数

- `type`：可选，`small`、`large`、`dragon` 或 `wither`。
- `speed`：可选，速度倍率，0.1 到 10。

## 示例

- `/fireball`
- `/fireball small`
- `/fireball large 2.5`

## 失败情形

- 类型无法识别。

## 相关命令

- `/firework`、`/nuke`、`/lightning`
