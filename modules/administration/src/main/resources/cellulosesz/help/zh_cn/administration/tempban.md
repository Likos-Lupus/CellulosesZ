# /tempban

临时封禁一个玩家账号。

## 行为

与 `/ban` 相同，但封禁会在指定时长后到期。时长受服务器上限约束；未设置上限时任意时长均可。封禁条目会在断开玩家之前
写入。该操作会记入审计记录。

## 参数

- `player`：要封禁的玩家。
- `duration`：例如 `1d`、`12h` 或 `1w`。
- `reason`：可选原因，由你填写。

## 示例

- `/tempban Alice 3d 破坏`

## 失败情形

- 时长不合法，或超过服务器上限。
- 找不到该名称对应的账号记录。
- 目标受保护。

## 相关命令

- `/ban`、`/unban`、`/tempbanip`
