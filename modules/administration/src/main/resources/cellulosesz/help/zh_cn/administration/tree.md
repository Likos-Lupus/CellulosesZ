# /tree

在你所看的方块处种树。

## 行为

放置并生成指定种类的树。支持 `tree`（橡树）、`birch`（白桦）、`redwood`（云杉）、`redmushroom`
（红色巨型蘑菇）、`brownmushroom`（棕色巨型蘑菇）、`jungle`（丛林树）、`junglebush`（丛林灌木） 和 `swamp`
（沼泽橡树）。树木生成在你所看的方块处。

## 参数

- `type`：受支持的树木种类之一。

## 示例

- `/tree tree`
- `/tree birch`
- `/tree redmushroom`

## 失败情形

- 树木类型无法识别。
- 你没有看向任何方块，或该处无法生成树木。

## 相关命令

- `/bigtree`、`/break`、`/ice`
