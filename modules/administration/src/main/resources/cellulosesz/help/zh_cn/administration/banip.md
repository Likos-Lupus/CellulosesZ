# /banip

封禁一个 IP 地址。

## 行为

使用原版 IP 封禁列表。目标可以是 IP 地址，也可以是在线玩家，此时会使用该玩家当前的地址。封禁在玩家进入服务器时生效，
并记入审计记录。原版仅完整支持 IPv4；IPv6 的覆盖情况取决于服务端实现，使用前请确认地址。

## 参数

- `target`：IP 地址，或使用其地址的在线玩家。
- `reason`：可选原因，由你填写。

## 示例

- `/banip 203.0.113.7`
- `/banip Alice`

## 失败情形

- 地址无法解析。
- 地址属于受保护的玩家。
- 地址已被封禁。
- 缺少权限。

## 相关命令

- `/tempbanip`、`/unbanip`、`/ban`
