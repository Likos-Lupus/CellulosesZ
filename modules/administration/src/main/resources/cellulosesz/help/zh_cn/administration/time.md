# /time

查看或修改世界时间。

## 行为

不带参数时显示当前时间。`set` 直接跳到指定时间，`add` 则在此基础上向前推进。最后的可选参数可以是 `all`
（所有世界）、维度 ID 或世界别名；省略时作用于你所在的世界。维度使用固定时间的世界无法修改。

支持 `day`、`noon`、`night`、`midnight`、`dawn`、`dusk`、24 小时制的 `17:30`、12 小时制的 `4pm`，或形如 
`4000ticks` 的游戏刻数。

## 参数

- `set`：跳到绝对时间。
- `add`：把时间向前推进。
- `value`：时间值，取自上述形式。
- `scope`：可选，`all`、维度 ID 或世界别名。

## 示例

- `/time`
- `/time set night`
- `/time set 17:30 all`
- `/time add 1000`

## 失败情形

- 时间值无法识别。
- 所选世界使用固定时间。
