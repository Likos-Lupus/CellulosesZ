# /customtext

显示指定的自定义服务器页面。

## 用法

- `/customtext <页面>`

## 行为

`<页面>` 是 `<配置目录>/cellulosesz/pages/<语言>/` 下不带 `.md` 的文件名。页面会按你的语言完整显示；如果该
语言没有对应文件，则使用 `en_us` 文件。修改文件后，下次查看页面时生效。

## 失败情况

- 不存在该名称的页面。
- 页面名称无效；请使用字母、数字、`_` 和 `-`。
- 服务器页面功能已关闭。
- 页面目录不存在，或文件过大无法显示。
