# /ignore

管理你不想接收其私聊的玩家名单。

## 行为

忽略某人后，对方发给你的私聊会被拒绝。名单按玩家保存，重启后仍然有效。你不能忽略自己，名称必须对应一名已知玩家。默认
名单上限为 128 人，服务器可以调整。

## 子命令

- `/ignore`：列出你已忽略的玩家。
- `/ignore add <player>`：不再接收该玩家的私聊。
- `/ignore remove <player>`：重新接收该玩家的私聊。

## 示例

- `/ignore`
- `/ignore add Alice`
- `/ignore remove Alice`

## 失败情形

- 找不到该名称对应的玩家记录。
- 你试图忽略自己。
- 忽略名单已满。

## 相关命令

- `/msg`、`/msgtoggle`
